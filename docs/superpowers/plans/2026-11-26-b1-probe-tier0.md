# B1：探测框架 + 第 0 档同源扩展 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立进程内数据源探测框架，并接入第 0 档四条同源扩展管道（腾讯报价字段、白银金银比、东财名义收益率/利差、周月K长历史+黄金日线种子）及三个新宏观信号。

**Architecture:** 复用 `core/factor-sources.js` 的"缓存+staleness 门+失败沿用"采集模式与 `core/signals.js` 的 noData 弃权信号模式；探测走生产 fetchFn（含 web 路由）经 hub 暴露为管理路由；所有产品差异只写在 `products/*/index.js`。

**Tech Stack:** Node.js ESM、零新增运行时依赖、`node --test`（`npm test`）、mock fetchFn。

**Spec:** `docs/superpowers/specs/2026-11-26-free-data-pipelines-design.md`（本计划论证自其 §5 管道 1–4、§9 决策 Q1/Q7；B2–B5 计划随后分批产出）

## Global Constraints

- 免费、无 key、无需注册的数据源；探测失败 = no-go 记录并跳过，不阻塞其余管道。
- 零新增运行时依赖；只用内置 fetch 与手写解析。
- 因子采集遵循 `factor-sources.js` 模式：时限门（默认 26h，金银比 30min）、失败沿用旧缓存、`fetchedAt:0` 表示下轮重试、错误可观测。
- 信号数据缺失/过期 → `noData` 弃权，绝不稀释综合分（`compositeScore` 现有语义）。
- 新采集不得阻塞决策周期（照抄 `collectFactors` 的后台 promise + 3s race 模式）。
- 产品差异（信号、权重、evolvable、dailySeed）只写在 `products/*/index.js`；引擎无产品常量。
- 测试全用 mock fetchFn，不依赖真实网络；`npm test` 全绿（现有 60+ 测试文件不许破坏）。
- 注释与提交信息用中文，风格与现有代码一致。
- 不改 LLM 决策主流程、交易频率计划、交易时段规则。

## Review Focus

1. **美/港腾讯载荷字段索引漂移**（字段 46/47/48 在 us/hk 载荷未必同义）→ 防御性解析：非有限值一律 `null`，估值信号在无 PB 时与现状逐位一致。归 Task 4，测试：非数值字段 → null 且 pe-only 评分不变。
2. **US10Y 与 UI10Y 日期错位**（两源发布日不同）→ `pairSeries` 只配对"同日或更近 ≤4 天"的观测，更旧则跳过。归 Task 2，测试：3 天间隔可配对、6 天间隔跳过。
3. **黄金日线种子污染 1h 信号 bar / 日开盘基准** → 午夜种子必须被 `isSessionOpen` 过滤。归 Task 5，测试：`barsFor('1h')` 不含种子桶；`sessionOpenPrice` 仍取时段内首个 tick。
4. **探测在 web 路由不可用环境的失败呈现** → 单源失败必须 `ok:false` 且 `detail` 保留原始错误（web/direct 双路径信息）。归 Task 1，测试：fetchFn 抛错 → detail 非空且其他源不受影响。
5. **valuationSignal 改动破坏现有评分** → `pbPercentile` 缺失时输出与改动前完全一致。归 Task 4，测试：现有 signals 测试原样通过 + 显式断言无 PB 时分数等于旧逻辑。

`factor-sources.js`：
- `collectFactors` 增加两条 `getEmFactor`：`{key:'factor:em:US10Y', secid:'171.US10Y'}`、`{key:'factor:em:US02Y', secid:'171.US02Y'}`（并入现有 `Promise.all`）。

- yieldCurve：`slope = f.value`（百分点）；`raw = slope<=0 ? 2 : slope<0.5 ? 1 : slope>2 ? -1 : 0`；`score = clamp(raw * (params.direction ?? 1), -2, 2)`。note 含 slope。
注册进 `SIGNALS` 导出表。

`engine.js` `evaluateSymbol`：ctx 增加 `breakeven: factors?.breakeven ?? null, yieldCurve: factors?.yieldCurve ?? null`。
